# BYU club email composer

**One web page that writes the emails a BYU club officer sends again and again:**
print orders to Print & Mail and Cougar Creations, poster-space requests to Campus
Scheduling, BYUSA Media Hub orders, account-balance and earnings requests to Accounting,
and the rest. You fill in a few boxes and it opens a finished draft in Outlook. **You
still read it and press send yourself. The page never sends anything.**

It was built by [Humor U](https://www.instagram.com/humoruofficial/), BYU's stand-up comedy club,
with Claude Code, so that officers spend less time on busy work and more on their members.

## Use it

1. Download `email.html` and open it in a browser. That's the whole install.
2. Search the file for `[YOUR` and replace each placeholder: club name, club email,
   venue, ticket price, meeting time, and so on. The settings are near the top of the
   `<script>` block.
3. Optional: paste it into your club's BrightSpot page, so every officer gets the same copy.

## Read this first

- **Unofficial.** This is not endorsed or maintained by BYUSA or BYU. Offices change their
  rules and addresses, so **check before you rely on it.**
- **Unmaintained, as-is.** There is no support, and please don't email Humor U about it.
- **Some addresses are blank on purpose.** Smaller offices (the dorm front desks, individual
  digital-signage contacts) are left out, so they aren't flooded by every club at once.
  Find the right person yourself, the way you would without this page.
- **First draft.** It's still written around Humor U's shows, so the wording assumes a
  monthly event. Edit the message text to fit your club.
